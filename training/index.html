Module 02: On-Hold Management & Exception Reporting
Standard protocol for handling unassigned bills and failed delivery attempts.
Exception Code Protocol
01
Unassigned Driver (Code 306)
Parcel arrived at station but no rider assigned within 2 hours. Mandatory assignment before 11:00 AM shift.
02
Unreachable Receiver (Code 404)
Phone unreachable after minimum 3 calls spaced 30 mins apart. Document call logs in system.
03
Address Discrepancy
Receiver requested redirection or address incomplete. Update system notes with new destination.
04
COD Amount Dispute
COD fee mismatch. Verify original invoice with sender store before releasing package.

Module 05: End-of-Day Service Point Protocol
Mandatory station close procedure, physical parcel audit, and daily inventory reconciliation.
Service Point EOD Checklist
01
Physical Parcel Audit
Count all physical parcels stored in the service point. Physical count must match system inventory 100%.
02
Status Resolution
Zero unhandled parcels allowed. All items must have updated status code (Delivered, In Transit, or On Hold reason).
03
Discrepancy Escalation
Report any missing or damaged parcels to the zone manager before station closing.
