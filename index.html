/logs Status Audit
Exports 20+ status-coded tracking logs complete with Service Type (CLT, CNT) and exact scan unit timestamps.
⚙️ Operational Date Filter Rules
• push (Branch Command):
Uses CREATED DATE = today. Best for daily branch creation metrics.
• push zone (Zone Groups):
Uses CURRENT TIME = today. Captures all bills with active scan movements today.
