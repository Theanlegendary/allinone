What Our Bot Does Every Day

  • ⚡
    Live API Sync: Automatically pulls real-time order data directly from Metfone TMS API servers.
  • 📦
    4-Stage Categorization: Categorizes bills by Pickup, Delivery, Transit (Send Mega), and Branch (Not Assign).
  • 📊
    3-Shift Clearance Tracking: Measures daily volume clearance changes across 9 AM Baseline, 2 PM Checkpoint, and 5 PM Total.
  • 🚀
    Telegram Auto-Pushes: Dispatches HD summary tables & Excel reports to 23 branch groups & 5 zone groups.
  • ⚙️
    Filter Rules: push uses CREATED DATE for creation metrics; push zone uses CURRENT TIME for active movements.
